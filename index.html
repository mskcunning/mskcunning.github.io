Freshmen Practical Final Exam: Coding Showcase

Showcase Your Coding Skills with a Creative Project

Project Overview

Welcome to your Freshmen Practical Final Exam! This is your chance to shine by creating a unique program or application using the coding platform of your choice (e.g., Python, Arduino, MIT App Inventor, Scratch, Robotics, Roblox Studio, or others you've learned). Your task is to design and build a solution—such as a game, app, interactive story, simulation, or hardware-based project—that demonstrates the programming skills you've mastered this year. The project should solve a problem, entertain, or educate, while meeting the technical requirements below. Let your creativity guide you!

Program Requirements

Defined Requirements

Your project must include the following, with Python examples provided for illustration:

  1. Input: Incorporate input from at least one of the following:
    • The user (e.g., button presses, text input, or other interactions with clear instructions).
    • A device (e.g., a sensor like temperature, light, or motion).
    • An online data stream (e.g., fetching weather data or social media feed).
    • A file (e.g., reading data from a text or CSV file).

    Python Example: User input for a simple game choice.

    choice = input("Enter 'r' for rock, 'p' for paper, or 's' for scissors: ")
if choice not in ['r', 'p', 's']:
    print("Invalid input! Please try again.")
  2. Variables: Use at least 2 variables to store and manipulate data within your program.

    Python Example: Storing a player's score and name.

    player_name = "Alex"
score = 0
score += 10  # Update score after a correct action
print(f"{player_name}'s score: {score}")
  3. List/Collection: Include at least one list (or other collection type, like an array or dictionary) to store and manage a collection of data, helping organize your program and support its purpose.

    Python Example: A list to store quiz questions.

    questions = ["What is 2+2?", "What is the capital of France?", "What is 5*3?"]
for question in questions:
    print(question)
  4. Function: Create at least one student-developed function that contributes to the program’s purpose. The function must have:
    • A clear, descriptive name.
    • A return type (if needed, e.g., returning a value like a number or string; void is acceptable if no return is necessary).
    • One or more parameters to accept input data.

    Python Example: A function to check if an answer is correct.

    def check_answer(user_answer, correct_answer):
    return user_answer.lower() == correct_answer.lower()
  5. Algorithm: Include an algorithm within your function that uses:
    • Sequencing (steps executed in order).
    • Selection (e.g., if/else statements or conditionals).
    • Iteration (e.g., loops like for, while, or repeat).

    Python Example: A function with sequencing, selection, and iteration to process a list of scores.

    def calculate_average(scores, minimum):
    total = 0
    count = 0
    for score in scores:  # Iteration
        if score >= minimum:  # Selection
            total += score  # Sequencing
            count += 1
    if count > 0:
        return total / count
    return 0
  6. Function Calls: Call your student-developed function multiple times within the program to demonstrate its utility.

    Python Example: Calling the check_answer function for multiple questions.

    answer1 = input("What is 2+2? ")
if check_answer(answer1, "4"):
    print("Correct!")
else:
    print("Wrong!")
answer2 = input("What is the capital of France? ")
if check_answer(answer2, "Paris"):
    print("Correct!")
else:
    print("Wrong!")
  7. Output: Provide output (tactile, audible, visual, or textual) that responds to the input and reflects the program’s functionality (e.g., displaying text, playing sounds, lighting LEDs, or rendering graphics).

    Python Example: Displaying a game result based on input.

    player_choice = input("Enter your move (rock/paper/scissors): ")
print(f"You chose {player_choice}! The opponent chose scissors.")
if player_choice == "rock":
    print("You win!")
else:
    print("You lose!")
  8. AI Usage: You may not use AI to write the script or program. However, you may use AI for troubleshooting (e.g., debugging errors or understanding concepts). If you use AI, document where and how you used it (e.g., “Used AI to understand why my loop wasn’t iterating correctly”).

    Python Example: Documentation of AI usage in comments.

    # Used AI to troubleshoot why my loop was skipping items
for i in range(len(questions)):
    print(f"Question {i+1}: {questions[i]}")
Project Guidelines

Project Guidelines

  • Choose Your Platform: Select a platform you’re comfortable with (e.g., Python, Arduino, MIT App Inventor, Scratch, robotics, Roblox Studio, or another you’ve learned).
  • Define Your Purpose/ Target Audience: Create a project with a clear purpose, such as solving a problem (e.g., a budget tracker), entertaining (e.g., a game), or educating (e.g., a quiz app).Indicate the target audience for your program.
  • Plan Your Project: Create either pseudocode or a flowchart to outline how your program will work, including how the input, variables, list, function, and output will interact. This planning step is required and must be submitted with your project.
  • Document Your Work: Provide a brief write-up (1-2 pages) or presentation explaining:
    • The purpose of your project and who it’s for.
    • How it meets each requirement (point to specific code or components).
    • Any challenges you faced and how you overcame them (including AI use, if applicable).
    • Instructions for running or using your project.
  • Test Thoroughly: Ensure your program works as intended and handles errors gracefully (e.g., invalid user input).
Example Project Ideas

Example Project Ideas

These are just to spark inspiration—create something unique!

  • Python: A text-based adventure game where the user inputs choices, a list tracks inventory, and a function calculates outcomes based on player stats.
  • Arduino: A smart plant monitor that uses a moisture sensor for input, stores readings in an array, and outputs watering alerts via LEDs or a buzzer.
  • MIT App Inventor: A quiz app where users input answers, a list stores questions, and a function scores responses with visual feedback.
  • Scratch: A multiplayer game where players input moves, a list tracks scores, and a function determines the winner with animated output.
  • QuadBot: A self propelled robot that can recognize people and objects and display them on a screen or say them out loud.
  • Roblox Studio: A virtual obstacle course where players input actions, a table tracks player progress, and a function spawns challenges with visual effects.
Deliverables & Evaluation

Deliverables

  1. Your working program (e.g., source code, project file, or hardware setup).
  2. Either pseudocode or a flowchart outlining your program’s structure.
  3. A brief write-up or presentation (as described in the guidelines).
  4. A screencast or video showcasing your project in action.
  5. Final Submission Document (make a copy for yourself)

Evaluation Criteria

  • Meets all technical requirements (input, variables, list, function, algorithm, output).
  • Includes a clear and complete pseudocode or flowchart.
  • Creativity and originality of the project idea.
  • Functionality (does it work as intended?).
  • Clarity of documentation and explanation of your process.
  • Proper acknowledgment of any AI use for troubleshooting.

Tips for Success

  • Start small and build incrementally—get a basic version working, then add features.
  • Test your code frequently to catch bugs early.
  • Use comments in your code to explain key sections, especially how you meet the requirements.
  • If stuck, break down the problem and troubleshoot one part at a time. You can seek help for specific errors!
  • Check out my sample solution to help you with formatting as well as reviewing what I am looking for from you!
