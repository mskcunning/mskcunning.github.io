    So what is Kali Purple?

    Kali Purple is the defensive, blue-team edition of Kali Linux. It is the same Debian-based system, plus a collection of tools for monitoring, detecting, and responding to attacks.

    It arrived with Kali 2023.1, for the project's tenth anniversary. Kali calls it a "SOC in a box": a Security Operations Center you can run in a lab.

    It is not a separate operating system. It is regular Kali with a purple theme and extra defensive packages. You can install it from its own installer, or add it to Kali you already have.

    It adds very few brand-new tools. Its value is gathering well-known free defensive tools in one place and sorting them by purpose.

    It still includes the normal attack tools, so one machine can play both sides of a purple-team exercise.

    The five NIST functions

    Kali Purple's Applications menu is organized by five functions from the NIST Cybersecurity Framework. Each function answers a question.

    FunctionQuestion it answersExample tools
    IdentifyWhat do we have, and where are the weaknesses?Greenbone vulnerability scanner
    ProtectHow do we prevent attacks?Firewall and hardening tools, Suricata in prevention mode
    DetectHow do we notice an attack?Suricata, Zeek, Arkime, Malcolm, Elastic Security, Wireshark
    RespondWhat do we do once we notice?TheHive, Cortex, CyberChef
    RecoverHow do we get back to normal?Backup and forensic tools; mostly process, not software

    NIST CSF 2.0, released in 2024, added a sixth function called Govern. Kali Purple does not have its own menu for it.

    Installing it safely

    You install Kali Purple into a virtual machine, a computer running inside your computer. That keeps the lab safe and easy to reset.

    1. Download the Purple installer from kali.org/get-kali, before class.
    2. Verify the file's SHA256 hash matches the one on the download page.
    3. Create the VM: 2 to 4 CPU cores, 8 GB RAM, 80 GB disk, host-only network.
    4. Run the graphical install and keep the Kali Purple tools selected.
    5. Log in and update the system, then reboot.

    Why check the hash? If someone tampered with the download, the hash will not match. That protects you from a supply-chain attack.

    The four tools you will use

    Wireshark captures network traffic so you can see every packet. Display filters like icmp or dns show only what you care about. Detect.

    Suricata is an intrusion detection system. You write a rule describing suspicious traffic, and Suricata writes an alert when it sees a match. Detect and Protect.

    Greenbone, also called OpenVAS, scans a computer for known weaknesses and ranks them by severity. Identify.

    CyberChef decodes and converts data found during an investigation, like turning Base64 text back into readable words. Respond.

    Heavier tools such as Zeek, Arkime, Elastic Security, and TheHive need more memory and setup. You will get a short tour of them and use them in a later lesson.

    The purple-team lab

    You work in pairs. The red partner runs an Nmap scan against the Kali Purple machine. The blue partner uses Suricata and Wireshark to prove the scan was seen, then writes a short incident note. Then you swap.

    Scan and capture only on the isolated lab network. Scanning systems you do not own or have permission to test can be illegal.

    Beginner activity

    Wireshark

    • sudo usermod -aG wireshark $USER
    • ip.addr == 192.168.56.101

    Suricata

    • sudo apt install suricata -y sudo suricata-update
    • echo 'alert icmp any any -> $HOME_NET any (msg:"LAB ICMP ping detected"; sid:1000001; rev:1;)' | sudo tee /etc/suricata/rules/local.rules
    • sudo suricata -T -c /etc/suricata/suricata.yaml -v sudo suricata -c /etc/suricata/suricata.yaml -i eth0
    • sudo tail -f /var/log/suricata/fast.log
