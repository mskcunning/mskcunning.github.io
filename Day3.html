    Activity 4

    Guess My Number: Duel Mode

    Build a number-guessing game, then flip it: make the computer guess YOUR number using a smart strategy.

    Concepts: while loops · conditionals · the random module

    Station files

    Concept slides (PowerPoint) Student worksheet (Word)

    Guided build

    Challenge tier: pick 1 or 2

    Score system

    Fewer guesses = higher score. Print the score each round.

    Play again

    Add a play-again loop that tracks the player’s BEST score across rounds.

    Computer guesses YOU

    Build you_pick_computer_guesses() using binary search: guess the midpoint, then narrow the range each time.

    Difficulty levels

    Let the player choose easy, medium, or hard, changing the range and guess limit.

    Worksheet questions

    Quick check: If the computer is guessing your number between 1–100 using the halfway strategy, about how many guesses should it take at most? Why?

    Reflection: Which version did you find more interesting to build — you guessing, or the computer guessing? Why?

    Activity 5

    Robot Commander: Pseudocode

    Think like a programmer before you write any code: break a task into exact steps using sequence, loops, and conditionals, then test your pseudocode by guiding a blindfolded junior “robot” through an obstacle course in the hallway.

    Robot rule: Your robot is a blindfolded junior who does exactly what each line says, nothing more and nothing less. No guessing what the programmer meant! Keep it safe: the robot moves slowly, the spotter stays right next to them, and if anyone says “STOP,” the robot freezes right away. Everyone stays inside the obstacle course area.

    The mission: hallway obstacle course

    Robot (a junior)

    Wears a blindfold and follows each line exactly. No peeking and no fixing mistakes.

    Programmer

    Reads the pseudocode to the robot one line at a time.

    Spotter

    Walks next to the robot, keeps them safe, and calls “STOP” if they get close to anything.

    Debugger

    Marks every line that goes wrong so your group can fix it.

    Robot commands

    CommandWhat the robot does
    MOVE FORWARD nTakes n steps forward
    TURN LEFT / TURN RIGHTTurns 90° in place
    STEP OVERSteps over a low obstacle in front of it
    REPEAT n TIMES … END REPEATDoes the steps inside n times
    IF condition THEN … END IFDoes the steps inside only if the condition is true (for example, IF obstacle ahead)

    Tasks

    Time permitting (optional)

    • Make your own command (like TURN AROUND) out of other commands and reuse it
    • Turn your pseudocode into real Python using what you learned in Activities 2–4
    • Trade pseudocode with another group and run theirs without changing a line
